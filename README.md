# 🚀 Falcon Portfolio

Un portfolio moderne et responsive développé en **HTML5** et **CSS3** pour présenter un développeur web Front-End.

## 📋 Aperçu

Cette page contient :

* Un header avec logo et menu de navigation
* Une section Hero de présentation
* Des boutons d'action (projets et téléchargement du CV)
* Des icônes de réseaux sociaux
* Une image de profil
* Une structure prête à accueillir les sections À propos, Projets, Compétences et Contact

## 🛠️ Technologies utilisées

* HTML5
* CSS3
